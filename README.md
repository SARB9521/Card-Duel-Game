# ♠️♥️♦️♣️ Card Duel Game ♣️♦️♥️♠️

A turn-based card game developed using C# and ASP.NET MVC.

## 🚀 Features
- Supports both single-player and multiplayer modes
- Card selection and turn-based gameplay
- Scoring system implementation
- Automatic winner determination
- Structured MVC architecture for maintainability

## 🛠 Technologies Used
- C#
- ASP.NET MVC
- HTML
- CSS
- JavaScript
